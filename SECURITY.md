# Security Policy

## Supported Versions

The following versions of **SCARLET** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of SCARLET seriously. If you discover a security vulnerability within the backend inference API, model loading pipeline, or frontend dashboard:

1. **Do not open a public GitHub issue.**
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/m4n1kya/Scarlet/security/advisories/new) or by contacting the maintainer directly through [@m4n1kya](https://github.com/m4n1kya).
3. Include a detailed description of the issue, steps to reproduce, and potential impact.

We aim to acknowledge all vulnerability reports within **48 hours** and provide a remediation timeline within **7 days**.
